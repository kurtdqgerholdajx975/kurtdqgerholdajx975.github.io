# Scary Teacher Games site

Static, responsive 30-game website built from the supplied game CSV and matching image folder.

- Open `index.html` for the homepage.
- Each game has its own page under `games/<game-slug>/`.
- `sitemap.xml` lists the homepage and all 30 game pages for `https://scary-teacher.com`.
- The 29 related game embeds use the iframe links supplied in the CSV. Scary Teacher uses the g.igroutka.ru URL supplied by you.
- Local game artwork is stored in `assets/games/`.

Deploy the contents of this folder at the web root for `scary-teacher.com`.
